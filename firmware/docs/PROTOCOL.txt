=========================================================================
 TCP 通信仕様 / PC スクリプト   (firmware / sensor モニタ)
=========================================================================
 更新: 2026-10-17

[役割]
  ESP32 (USR-ES1 / W5500) = TCP サーバ
  PC                     = TCP クライアント (直結 LAN ケーブル想定)

[接続]
  ESP32 IP   : 192.168.1.50  (固定)
  サブネット : 255.255.255.0
  TCP ポート : 5000
  PC 側 IP   : 192.168.1.10/24 など、ESP32 と同一セグメントにする
               (直結の場合は DHCP サーバが無いので PC も固定 IP にする)

[メッセージ形式]
  テキスト 1 行。区切りは改行 (\n)。UTF-8。
  受信側 (ESP32) は '\n' または '\r' で 1 通とみなし、最大 127 バイト
  (= MSG_MAX-1)。128 バイトを超えた行は破棄する。
  推奨は「一言メッセージ」程度 (画面には約 18 文字 x 5 行で折返し表示)。
  接続が切れた時点で未改行の残りがあれば、それも 1 通として扱う。

[応答]
  ESP32 は 1 通受信すると同じ接続へ "OK\n" を返す (ベストエフォート)。

[PC スクリプト]
  pc/send_message.py  (Python 3 標準ライブラリのみ)

  例:
    python send_message.py "こんにちは"                    # 1 回送信
    python send_message.py "hello" --host 192.168.1.50 --port 5000
    python send_message.py                                 # 対話モード
      # 対話モード: 文字列を入力して Enter。空行で終了。

  注意 (Windows/ファイアウォール):
    初回は Windows Defender 等が python の送信をブロックする場合がある。
    許可するか、一時的にファイアウォールを確認する。
