=========================================================================
 ESP32 DevKit-C  ピン割り当て / 配線メモ   (firmware / sensor モニタ)
=========================================================================
 更新: 2026-10-17
 モジュール: BME680 (I2C), MPU-9250 (I2C), ST7789 (SPI), USR-ES1/W5500 (SPI)
 ファーム側の実体定義: include/config.h  (platformio.ini の build_flags と
                        不一致ならコンパイル時に static_assert で止まる)

[I2C]  BME680 と MPU-9250 が共有 (400kHz)
  GPIO21  SDA    BME680 SDA / MPU-9250 SDA
  GPIO22  SCL    BME680 SCL / MPU-9250 SCL
  3V3/GND は各モジュールへ供給

[SPI]  ST7789 と USR-ES1 が共有バス (CS のみ別)
  GPIO14  SCK    ST7789 SCL / USR-ES1 SCLK
  GPIO13  MOSI   ST7789 SDA / USR-ES1 MOSI
  GPIO12  MISO   USR-ES1 MISO のみ (ST7789 は書き込み専用)
  GPIO15  CS     ST7789   (チップセレクト)
  GPIO18  CS     USR-ES1  (チップセレクト)
  GPIO2   DC     ST7789 データ/コマンド
  GPIO4   RST    ST7789 リセット
  --      RST    USR-ES1 の RST は 3.3V 固定 (GPIO 未接続)

[I2C アドレス]  (実機に合わせて自動判別: 上が優先)
  BME680   0x77 -> 0x76
  MPU-9250 0x68 -> 0x69

[その他]
  ST7789 解像度 : 240 x 240
  SPI クロック  : ST7789 40MHz / W5500 はライブラリ既定 (約14MHz)
  TCP           : ESP32 = サーバ 192.168.1.50:5000 (固定IP)
                  PC    = クライアント 192.168.1.10/24, 直結LANケーブル想定
  MAC アドレス  : DE:AD:BE:EF:FE:01

[デバッグ時の確認ポイント]
  * CS は初期化前に HIGH 固定 (ST7789=15, USR-ES1=18)
  * SPI は 1 本のバスを 2 チップで共有。ST7789 描画中は W5500 に触らない
  * シリアルログ 115200bps に各モジュールの OK/NG と 2 秒毎サマリを出力
  * 画面右下に BME/IMU の検出状態と IP, 受信メッセージ数を表示

[参考: KiCad 図面との差異]
  sensor.kicad_sch のグローバルラベルは VSPI (CLK=18/MOSI=23/MISO=19,
  CS=5, RESET=4) 表記だが、本ファームは指示どおり ST7789 CS=15,
  USR-ES1 CS=18 の構成で、SPI を GPIO12/13/14 に割り当てている。
  (=CLK 18 と USR-ES1 CS 18 の衝突を避けるため)
