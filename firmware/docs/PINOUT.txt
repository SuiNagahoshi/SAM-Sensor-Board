=========================================================================
 ESP32 DevKit-C  ピン割り当て / 配線メモ   (firmware / sensor モニタ)
=========================================================================
 更新: 2026-10-17  (液晶の実配線に合わせて修正)
 モジュール: BME680 (I2C), MPU-9250 (I2C), ST7789 (SPI), USR-ES1/W5500 (SPI)
 ファーム側の実体定義: include/config.h  (platformio.ini の build_flags と
                        不一致ならコンパイル時に static_assert で止まる)

[I2C]  BME680 と MPU-9250 が共有 (400kHz)
  GPIO21  SDA    BME680 SDA / MPU-9250 SDA
  GPIO22  SCL    BME680 SCL / MPU-9250 SCL

[SPI 液晶 ST7789]  実測の配線 (2026-10-17 確認)
  GPIO18  SCK    ST7789 SCL/SCK
  GPIO23  MOSI   ST7789 SDA/MOSI
  GPIO15  CS     ST7789 CS
  GPIO19  DC     ST7789 DC/RS
  GPIO17  RST    ST7789 RES/RST
  3V3     BLK    バックライト (直結)
  --      MISO   未使用 (液晶は書き込み専用)

[SPI USR-ES1/W5500]  ← 実際の配線を教えてください (未確定)
   各ピンの接続先 GPIO を記入する:
     SCLK = ?
     MOSI = ?
     MISO = ?
     CS   = ?
     RST  = ?
   INT は未接続。

   現在のファーム設定 (config.h):
     PIN_SPI_MISO = -1  (MISO 未確定のため)
     PIN_ETH_CS   =  5  (暫定。実際の CS に合わせて変更)

[I2C アドレス]  (実機に合わせて自動判別: 上が優先)
  BME680   0x77 -> 0x76
  MPU-9250 0x68 -> 0x69

[その他]
  ST7789 解像度 : 240 x 240
  SPI クロック  : 10MHz (ブレッドボード配線で 40MHz が不安定だったため。
                  安定確認後に platformio.ini の SPI_FREQUENCY を上げてよい)
  TCP           : ESP32 = サーバ 192.168.1.50:5000 (固定IP)
                  PC    = クライアント 192.168.1.10/24, 直結LANケーブル想定
  MAC アドレス  : DE:AD:BE:EF:FE:01

[切り分けテスト]
  pio run -e tft_test -t upload   … 液晶のみ (赤→緑→青→白→黒)
  画面が真っ暗なままなら「バックライト / 電源 / ピン」を疑う。

[バックライトが点かないときのチェック]
  1. テスタで 液晶 VCC-GND = 約3.3V / BLK-GND = 約3.3V を確認
  2. 液晶以外の配線を外し VCC/GND/BLK(3V3) だけで点灯するか確認
  3. モジュールによっては BLK が LED のカソードで GND に落とすと点灯する
     (点かない場合は BLK を GND にも試す。ただし自己責任で)
  4. モジュールが 5V 入力(内部3.3Vレギュレータ)タイプか型番を確認
